reactive_counter.koy 
// 🚀 Объявление реактивных сигналов
signal counter = 0;
signal user = "Developer";

// 🔔 Подписка на изменения состояния
counter.listen((val) {
    Logger.log("Счётчик обновлён: " + val);
});

Logger.log("Привет, " + user + "!");

// ⚡ Обновление значения триггерит все активные слушатели
counter.value = 1;
counter.value = 42;

Справочник по языку

Краткий обзор основных команд и структур Koy.

1. Сигналы (Signals)

Объявление реактивного состояния производится ключевым словом signal.

Изменение значения через свойство .value автоматически уведомляет всех подписчиков.

2. Слушатели (Listen)

Функция .listen((val) { ... }) привязывает анонимную функцию к сигналу.

Код внутри автоматически срабатывает каждый раз при вызове `.value = newValue`.

3. Вывод и Логи

Вывод информации в консоль осуществляется через встроенный класс Logger.log(...).

Поддерживается конкатенация строк, вывод чисел и переменных.

4. Интерактивный REPL

Запустите команду koy без параметров, чтобы войти в режим интерактивной консоли.

Для выхода из консоли используйте команду exit().

Быстрый старт

  1. Загрузка дистрибутива
    Скачайте исполняемый файл KoySetup.exe из официального релиза на GitHub.
  2. Мгновенная установка
    Запустите инсталлятор и нажмите Install. Через ~3 секунды среда будет полностью настроена.
  3. Запуск Koy Terminal
    Откройте меню «Пуск» и запустите ярлык Koy Terminal или введите koy в любой консоли.
  4. Запуск скриптов
    Выполняйте готовые файлы с кодом одной командой: koy script.koy или просто перетащите файл на иконку koy.exe.
